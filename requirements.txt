# Beschreibung
# ------------
# Keine PyPI-Pakete. pip-Install ist leer, weil Live-Backup, Shrink
# und Packen keine Python-Plugins brauchen, sondern Kernel- und
# Dateisystem-Werkzeuge:
#
#   Live-Backup  – Rohlesen des Blockgeraets (os.read/os.write, Stdlib).
#                  Ein PyPI-Paket ersetzt das nicht; Snapshots waeren
#                  LVM/btrfs, nicht pip.
#   Shrink       – ext4 verkleinern kann nur e2fsprogs (resize2fs,
#                  e2fsck). Dafuer gibt es kein sicheres Python-Modul.
#   Packen       – zstd als Debian-Paket. Das PyPI-Modul zstandard
#                  waere nur ein zweiter Kompressor mit C-Extension
#                  und wuerde resize2fs trotzdem nicht ersetzen.
#   Geraete      – lsblk (util-linux), nicht pyudev.
#
# Laufzeit auf dem Raspberry Pi (apt, nicht pip):
#
#   sudo apt install python3 e2fsprogs util-linux mount zstd policykit-1
#
